# Modify the items data frame to run the reduction on all items together

Modify the items data frame to run the reduction on all items together

## Usage

``` r
run_all_together(items)
```

## Arguments

- items:

  A data frame containing the items either generated by AI or supplied
  by the user.

## Value

A data frame whose `attribute` and `type` columns are modified so the
entire sample can be analyzed as one item type.
